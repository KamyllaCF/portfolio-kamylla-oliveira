# Portfólio Pessoal - Kamylla Cristina

Projeto desenvolvido para a atividade prática de Fundamentos da Programação Web.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Estrutura do site

O site possui navegação por âncoras em uma única página, com as quatro seções obrigatórias:

- Sobre mim
- Formação
- Portfólio
- Contato
